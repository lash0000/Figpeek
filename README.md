## About
Figpeek is a Figma plugin a thumbnail generator. With Figpeek you can create and experiment your thumbnail with ease. Organize your Figma projects with Figpeek now, it's FREE!

## Contribute
If you want to run this yourself, use Figma Desktop then Go to `Plugins menu → Development → Import plugin from manifest`
```
pnpm install
pnpm run build
```
